# Бесплатный запуск Секретки

Сервер — обычное Node.js-приложение (одна зависимость, `ws`) с файловым хранилищем. Его можно запустить где угодно.

## Вариант 1. На своём ноутбуке (самый простой, рекомендуемый)

```bash
npm install
npm start
```

- Открой `http://127.0.0.1:8080` у себя.
- Сервер печатает LAN-адреса — телефон/ноутбук в той же сети заходит по `http://<IP>:8080`.
- Чтобы работало из интернета (например, если у девушки мобильный интернет), придётся пробросить порт 8080 на роутере (port forwarding) — зависит от роутера, и лучше тогда добавить HTTPS (см. ниже).

## Вариант 2. Бесплатные облачные хостинги

| Площадка | Что даёт | Нюансы |
|---|---|---|
| **Render** (free) | Web Service, авто-HTTPS, WebSocket поддерживается | Засыпает после ~15 минут без трафика (первое открытие ~30–50 с); 750 часов/мес |
| **Fly.io** | Бесплатный лимит ресурсов, авто-HTTPS, WebSocket | Нужна банковская карта для регистрации |
| **Oracle Cloud** (Always Free) | Настоящий VPS навсегда бесплатно, полный контроль, TLS-сертификаты | Нужна регистрация с картой, сложнее настройка |
| **Glitch / Replit** | Быстро, бесплатно | Нестабильно для постоянного использования, засыпание |

### Render (самый простой облачный вариант)

1. Залей репозиторий на GitHub.
2. В Render: **New → Web Service** → выбери репозиторий.
3. Build: `npm install` · Start: `node server.js`.
4. Free Instance достаточно. Render сам выдаст адрес вида `https://sekretka.onrender.com` — открой его и пользуйся.

WebSocket учтён — код использует ту же TCP-сессию, никаких доп. настроек.

### Docker (для любого VPS)

```bash
docker build -t sekretka .
docker run -d -p 8080:8080 -v sekretka-data:/app/data sekretka
```

## HTTPS

Приложение работает и по HTTP (для LAN это нормально). Из интернета лучше использовать HTTPS — бесплатные хостинги (Render, Fly.io) дают его автоматически. На своём VPS — certbot (Let's Encrypt).

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `8080` | Порт |
| `HOST` | `0.0.0.0` | Слушать все интерфейсы |
| `DATA_FILE` | `data.json` рядом с сервером | Файл хранилища |
| `DEMO=1` | — | Создать демо-аккаунты `demo_alice`/`demo_bob` |
