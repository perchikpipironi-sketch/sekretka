# Секретка на Render — пошагово

Render — бесплатный хостинг, который умеет Node + WebSocket. Публичный адрес будет
постоянным: `https://<имя-сервиса>.onrender.com`, он не меняется при перезапусках
(в отличие от Quick Tunnel на ноуте).

## Шаг 1. Выложить код на GitHub

В папке `sekretka` (там, где лежит `server.js`):

```powershell
git init
git add .
git commit -m "Секретка: шифрованный мессенджер"
git branch -M main
git remote add origin https://github.com/<твой-логин>/sekretka.git
git push -u origin main
```

Файл `.gitignore` уже исключает `node_modules/`, `data.json`, `media/` и скриншоты —
личная переписка в репозиторий не попадёт.

## Шаг 2. Создать сервис на Render

1. Зайти на https://render.com → **Sign up with GitHub** (карта не нужна).
2. **New +** → **Blueprint** → выбрать репозиторий `sekretka`.
3. Render увидит `render.yaml` и предложит создать web-сервис `sekretka` (план **Free**).
   Нажать **Apply**. Сборка займёт 1–3 минуты.
4. Готово: сверху появится ссылка вида `https://sekretka-xxxx.onrender.com`.
   Её и отправляй девушке.

Проверка, что сервис жив: открыть `https://<адрес>/api/health` — должно вернуть
`{"ok":true}`.

## Шаг 3. Что важно знать про бесплатный план

| Что | Как на бесплатном Render |
|---|---|
| Адрес | постоянный, `*.onrender.com` (HTTPS из коробки) |
| Сон | после ~15 мин без запросов сервис засыпает; первое открытие — 30–60 с |
| Данные | эфемерные: после деплоя/перезапуска аккаунты и история обнуляются (на free нет диска) |
| WebSocket | работает (новые сообщения и «печатает…» приходят сразу) |
| Трафик | 100 ГБ/мес — для переписки с запасом |

**Про данные.** На бесплатном плане постоянного диска нет, поэтому сервер теряет
`data.json` при перезапуске. Варианты:

- оставить ноут + туннель как основной вариант (данные на диске, живут месяцами),
  а Render держать как «запасной адрес»;
- перейти на платный инстанс Render ($7/мес) и раскомментировать `disk:` в
  `render.yaml` — тогда данные сохраняются.

Шифрование при этом не страдает: открытые ключи друзей и адреса есть только на
сервере **в зашифрованном виде** — сервер и Render видят лишь шифротекст.

## Docker (если разворачиваешь на VPS)

```bash
docker build -t sekretka .
docker run -d -p 8080:8080 -v $(pwd)/data:/app/data \
  -e DATA_FILE=/app/data/data.json -e MEDIA_DIR=/app/data/media sekretka
```

`Dockerfile` уже лежит в проекте.
